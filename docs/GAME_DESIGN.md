# ゲームデザイン資料（たたき台）

> これは **アイデアのたたき台** です。自由に書き換えて、自分だけの物語にしてください。
> ゲーム作りでは「全部決めてから作る」より、**作りながら決めていく**ほうがうまくいくことが多いです。

---

## 1. コンセプト（ひとことで）

**「光の剣で、銀河を闇から救え。」**

- ジャンル：3D アクション（近接バトル）
- 視点：三人称（キャラクターの後ろから）
- 気持ちよさの中心：**斬る・防ぐ・弾く** の駆け引き

## 2. 物語（あらすじ案）

銀河の平和を守ってきた「光の守護者」たちは、謎の闇の軍団によって次々と倒されてしまった。
最後に残った見習いの守護者である主人公は、師から受け継いだ光の剣を手に、
闇に支配された星々を一つずつ解放していく。
そして銀河の中心で待つ、闇の軍団の首領との最終決戦へ――。

## 4. バトルシステム

### 今できること（プロトタイプ）
- [x] 移動・ダッシュ・ジャンプ
- [x] 2段コンボ斬り
- [x] ガード（正面のみ）
- [x] 攻撃を弾かれるとのけぞる
- [x] 敵の「ため」中に斬ると怯む
- [x] ヒットストップ（当たった瞬間の一時停止で手応えを出す）

### 今後追加したいアイデア
- [ ] **ジャストガード（パリィ）**：攻撃が当たる直前にガードすると、相手が大きく崩れる
- [ ] **ビーム反射**：敵の撃ったビームをガードで跳ね返す
- [ ] **フォース的な超能力**：敵を押し飛ばす・引き寄せる（MP を消費）
- [ ] **回避（ステップ）**：素早く横に避ける
- [ ] **鍔迫り合い**：お互いの剣がぶつかったら連打勝負
- [ ] **セーバーの色**：ステージクリアで新しい色が解放される

## 5. 作る順番のめやす

1. **今のプロトタイプで「戦って楽しい」を作り込む** ← 一番大事！
2. 音とエフェクトを付ける
3. ステージ1つを最後まで完成させる（タイトル → ステージ → クリア画面）
4. ステージを増やす
5. ストーリー演出を入れる

> 💡 見た目より先に「操作して楽しいか」を確認するのがコツです。
> 四角や丸のままでも楽しければ、見た目を良くしたときにもっと楽しくなります。
