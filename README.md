# Light Saber ⚔️ — 銀河を救う3Dライトセーバーバトル

Unity で作る、ライトセーバーを使った3Dバトルゲームのプロジェクトです。
**ゲーム制作が初めての人**が、動くものを触りながら少しずつ学べるように作っています。

> このリポジトリには「まず遊べる」最小限の試作（プロトタイプ）が入っています。
> 四角や丸の仮の見た目ですが、**移動・斬撃コンボ・ガード・敵AI・勝敗判定**まで一通り動きます。
> ここを出発点に、少しずつ自分のゲームに育てていきましょう。

## 2. プロジェクトの作り方（最初の1回だけ）

### ステップ 1：Unity プロジェクトを新規作成

1. Unity Hub を開き「**新しいプロジェクト**」をクリック
2. テンプレートは **「Universal 3D」**（URP）を選ぶ
3. プロジェクト名（例: `LightSaberGame`）と保存場所を決めて「プロジェクトを作成」

### ステップ 2：このリポジトリのファイルを入れる

1. GitHub のこのページで「**Code → Download ZIP**」（または `git clone`）
2. ZIP を解凍し、中の **`Assets/LightSaber` フォルダ**を、
   作ったプロジェクトの **`Assets` フォルダの中**にコピー
3. Unity に戻ると自動で読み込まれます（少し待ちます）

### ステップ 3：入力設定を確認（エラーが出たときだけ）

基本的にはそのまま動くように作っていますが、もし入力関係のエラーが出たら：

`Edit → Project Settings → Player → Other Settings → Active Input Handling` を **「Both」** にして、Unity を再起動してください。

### ステップ 4：シーンを自動生成して遊ぶ

1. Unity 上部のメニューに **「Light Saber」** が増えているので、
   **`Light Saber → プロトタイプシーンを作成`** をクリック
2. 「完成！」と出たら、画面上部の **▶（再生）ボタン**を押す
3. 遊べます！ もう一度 ▶ を押すと止まります

> ⚠️ **大事な注意**：再生中（▶ が青い間）にインスペクターで変えた数値は、**停止すると元に戻ります**。
> 試しに調整するのには便利ですが、確定したい値は停止してから入力しましょう。

## 3. 遊び方（操作方法）

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| ダッシュ | `Shift` を押しながら移動 |
| ジャンプ | `Space` |
| 攻撃 | **左クリック**（タイミングよく連打すると右斬り→左斬りのコンボ） |
| ガード | **右クリック長押し**（正面からの攻撃を防ぐ） |
| セーバー ON/OFF | `F` |
| カメラ | マウスを動かす |
| マウスカーソルを出す | `Esc`（クリックで戻る） |
| リトライ | 勝敗がついた後に `R` |

**戦い方のヒント**
- 敵は斬る前にセーバーを**振りかぶって光らせます**（＝攻撃の合図）。そこでガード！
- 敵が振りかぶっている最中に斬ると、**怯ませて攻撃をキャンセル**できます
- 敵もときどきガードします。弾かれたら一度距離をとりましょう

## 4. ファイルの説明

```
Assets/LightSaber/
├── Scripts/
│   ├── GameInput.cs          … キーボード・マウス入力をまとめたもの
│   ├── PlayerController.cs   … プレイヤーの移動・ジャンプ・攻撃・ガード
│   ├── Lightsaber.cs         … ライトセーバー（斬る動き・当たり判定・ガード・ON/OFF）
│   ├── Health.cs             … HP・ダメージ・ガード判定・倒れる処理
│   ├── EnemyAI.cs            … 敵の頭脳（近づく→ため→斬る、ときどきガード）
│   ├── ThirdPersonCamera.cs  … プレイヤーを後ろから追うカメラ
│   ├── GameManager.cs        … HPバー表示・勝敗判定・リトライ
│   ├── CharacterAnimator.cs  … 移動の速さに合わせて 待機⇔走り アニメを切り替える
│   ├── SaberHandIK.cs        … 人型モデルの手をセーバーの柄に合わせる（IK）
│   └── Editor/               … Unity エディタの中だけで動く便利ツール
│       ├── PrototypeSceneBuilder.cs     … シーンを自動で組み立てる
│       ├── EnvironmentBuilder.cs        … 建物・街を自動で配置する
│       ├── CharacterModelSetupWindow.cs … 人型モデルに差し替えるウィンドウ
│       └── BuilderUtil.cs               … 上の3つで共通して使う関数
├── Materials/   （自動生成）色の設定
├── Animations/  （自動生成）Animator Controller
├── Models/      （自分で作る）Mixamo などの FBX を入れる場所
└── Scenes/      （自動生成）Prototype.unity
```

### Unity の基本用語

| 用語 | 意味 |
|---|---|
| **シーン (Scene)** | ゲームの1画面・1ステージ。ここにいろいろな物を置く |
| **ゲームオブジェクト (GameObject)** | シーンに置く「物」。プレイヤー、敵、地面、カメラ…全部これ |
| **コンポーネント (Component)** | ゲームオブジェクトに付ける「機能部品」。自分で書いたスクリプトも部品の1つ |
| **インスペクター (Inspector)** | 選んだオブジェクトの部品と数値を見たり変えたりする画面 |
| **ヒエラルキー (Hierarchy)** | シーンにある物の一覧（親子関係も表示） |
| **プレハブ (Prefab)** | オブジェクトの「設計図」。敵を何体も出すときなどに使う |

### 仕組みのイメージ

```
[Player]  ← PlayerController, Health, CharacterController
  ├─ Visor（顔の向き）
  └─ Lightsaber（手首） ← Lightsaber.cs  ※ここを回転させて「斬る」動きを作っている
       ├─ Hilt（柄）
       └─ BladeRoot（ON/OFFで伸び縮み）
            ├─ Blade（光る刃）
            └─ BladeLight（周りを照らす光）
```

敵も同じ構造で、`PlayerController` の代わりに `EnemyAI` が付いています。
**同じ `Lightsaber.cs` を、プレイヤーは「キー入力」で、敵は「AI」で操作している**のがポイントです。

## 5. C言語を知っている人向け：C# のポイント

C# は C言語の仲間なので、`if` / `for` / `while` / `int` / `float` などの書き方はほとんど同じです。

| C言語 | C#（Unity） | メモ |
|---|---|---|
| `struct` + 関数 | `class` | データと処理（メソッド）をひとまとめにしたもの |
| `main()` から始まる | `Start()` / `Update()` を Unity が呼ぶ | `Update()` は**毎フレーム**（1秒に60回など）自動で呼ばれる |
| `printf("%d", x);` | `Debug.Log($"{x}");` | Console ウィンドウに表示される |
| `malloc` / `free` | `new` だけ | 片付けは自動（ガベージコレクション） |
| 関数ポインタ | `event` / `Action` | `health.Died += OnDied;` で「死んだら OnDied を呼んで」と登録 |
| `#define` / `#if` | `#if` は同じ | `GameInput.cs` で使っています |
| `1.5` (double) | `1.5f` (float) | Unity では `f` を付けた float をよく使う |

### Unity 特有の書き方

```csharp
public class Sample : MonoBehaviour   // MonoBehaviour を継承すると「部品」になる
{
    [SerializeField] float speed = 5f; // インスペクターで数値を変えられるようになる

    void Start()  { /* 最初に1回だけ呼ばれる */ }
    void Update() { /* 毎フレーム呼ばれる */ }
}
```

- **`Time.deltaTime`**：前のフレームからの経過秒数。`速さ × Time.deltaTime` にすると、パソコンの性能に関係なく同じ速さで動く
- **コルーチン (`IEnumerator` + `yield return`)**：何フレームにもまたがる処理を順番に書ける仕組み。`Lightsaber.cs` の `SwingRoutine()` が例

## 6. 最初にやってみる改造（練習問題）

まずは**数値を変えるだけ**で、ゲームの手触りがどう変わるかを体験しましょう。
ヒエラルキーでオブジェクトを選び、インスペクターで数値を変えます。

- [ ] **レベル1**：`Player` の `PlayerController` → `Walk Speed` を 10 にしてみる
- [ ] **レベル1**：`Player/Lightsaber` の `Swing Duration` を 0.15 にして高速斬り
- [ ] **レベル1**：`Enemy_1` の `EnemyAI` → `Guard Chance` を 0.9 にして鉄壁の敵にする
- [ ] **レベル2**：`Materials/BladeBlue` の Emission の色を変えて、緑や紫のセーバーにする
- [ ] **レベル2**：敵をコピー（`Ctrl + D`）して増やしてみる
- [ ] **レベル3**：`Lightsaber.cs` の `slashAStart` などの角度を変えて、斬り方を変える
- [ ] **レベル3**：`Debug.Log("当たった！");` を `CheckHits()` に入れて、Console に表示させる

## 7. 見た目をリアルにする（人型キャラ・街）

### 7-1. 建物・街を置く（ワンクリック）

`Light Saber → プロトタイプシーンを作成` で、**街も一緒に自動で作られる**ようになりました。
（今のシーンに街だけ追加・作り直ししたいときは `Light Saber → 建物・街を配置` を使います）

作られるもの：

| 場所 | 中身 |
|---|---|
| 中央 | 光るラインに囲まれた戦闘エリア |
| その外側 | 身を隠せる低い壁、木箱、街灯（本物の光源つき） |
| さらに外 | 窓が光るビル（屋上設備・アンテナ付き） |
| 遠く | 高層ビル群、星空、霧（遠くがかすんで奥行きが出る） |

> 💡 `EnvironmentBuilder.cs` の `Random.InitState(2024);` の数字を変えると、別の配置の街になります。

### 7-2. キャラクターを人型にする（Mixamo）

[Mixamo](https://www.mixamo.com/) は Adobe の**無料**サイトです。人型の3Dキャラクターと、何千種類ものアニメーションをダウンロードできます（Adobe アカウントが必要です）。

#### ① ダウンロードする（全部で3つ）

| 何を | Mixamo での操作 | ダウンロード設定 |
|---|---|---|
| **キャラクター** | 上の「Characters」タブで好きなキャラを選ぶ | Format: **FBX for Unity (.fbx)** / Pose: **T-pose** |
| **待機アニメ** | 「Animations」タブで `idle` と検索して選ぶ | Format: **FBX for Unity** / Skin: **Without Skin** |
| **走りアニメ** | `running` と検索。右側の **In Place** にチェック | Format: **FBX for Unity** / Skin: **Without Skin** |

> 敵用に別のキャラ（鎧を着たキャラなど）も選ぶと、雰囲気がぐっと出ます。
> アニメーションは、キャラクターを選んだ状態で探すと、そのキャラで動きをプレビューできます。

#### ② Unity に入れる

1. Project ウィンドウで `Assets/LightSaber` を右クリック → `Create → Folder` で **`Models`** フォルダを作る
2. ダウンロードした FBX を、**`Models` フォルダにドラッグ＆ドロップ**

#### ③ セットアップする

1. `Light Saber → プロトタイプシーンを作成` でシーンを開いておく
2. `Light Saber → キャラクターモデルを設定` を開く
3. 「設定する相手」で **プレイヤー** を選ぶ
4. Project ウィンドウから3つの FBX をそれぞれの欄にドラッグ
5. **「セットアップ！」** を押す
6. 敵も同じように（「設定する相手」を **敵** にして）設定する
7. **`Ctrl + S`** で保存 → ▶ で遊ぶ！

自動で次のことをしてくれます：
- FBX を人型（Humanoid）に設定し、アニメをループ再生にする
- 「止まる ⇔ 走る」を切り替える Animator Controller を作る
- カプセルを人型モデルに差し替える
- **手が自動でセーバーを握る**ようにする（IK）

> ⚠️ 「プロトタイプシーンを作成」をもう一度実行すると、カプセルに戻ります。そのときはもう一度セットアップしてください。

#### ④ 握り方の仕組みと調整（お好みで）

`Saber Hand IK`（`Player/Model` に付いています）が、毎フレーム次のことをしています。
1. 右手をセーバーの位置へ伸ばす（IK）
2. 手首の向きをセーバーに合わせる
3. **セーバーを手のひらに吸着させる**（走っても手から離れない）

見た目が不自然なときは、再生中に `Player/Model` を選んで数値をいじってみてください。
- 手首の向きが変 → `Hand Rotation Offset` の角度を調整（または `Align Hand` をオフ）
- `Left Hand Weight` を 1 にすると**両手持ち**になります

良い値が見つかったら、**停止してから**同じ値を入れ直しましょう（再生中の変更は元に戻るため）。

#### ⑤ キャラクターに色が付いていないとき

1. Project ウィンドウで、キャラクターの FBX（With Skin のもの）をクリックして選ぶ
2. `Light Saber → 選んだモデルの色を直す` を押す

> FBX の中に入っている画像（テクスチャ）を取り出して、色が付くようにします。
> これから「セットアップ！」するモデルは自動で直ります。
> それでも白いままなら、Mixamo で Format を **FBX for Unity (.fbx)** にしてダウンロードし直してください。

### 7-3. もっとリアルにしたいとき

| やりたいこと | 方法 |
|---|---|
| セーバーを光らせる | 下の「セーバーを光らせる（Bloom）」 ← **効果大！まずはこれ** |
| 本格的な建物・背景 | **Unity Asset Store** で `sci-fi` と検索し、Price を **Free** で絞り込む |
| 攻撃・ガード・倒れるアニメ | Mixamo の `sword slash` などを使う（次のステップで一緒に作りましょう） |

> 「Built-in to URP」→「Material Upgrade」にチェック → 「Initialize And Convert」を実行します。

## 8. これからのロードマップ

焦らず、**1つずつ「動いた！」を積み重ねる**のがコツです。

| 段階 | 内容 | 学べること |
|---|---|---|
| ✅ **0. 試作** | 今の状態。仮の見た目で遊べる | Unity の基本操作 |
| **1. 光らせる** | URP の **Bloom（ブルーム）** でセーバーをぼわっと光らせる（下記参照） | ポストプロセス |
| **2. 敵をプレハブ化** | 敵をプレハブにして、Wave（第1波・第2波…）で出現させる | Prefab, Instantiate |
| **3. 音を付ける** | ブォンという起動音、斬る音、ぶつかる音 | AudioSource |
| **4. エフェクト** | セーバーがぶつかった時の火花、斬撃の軌跡 | Particle System, Trail Renderer |
| ✅ **5. 人型キャラ** | 人型モデルとアニメーションに置き換える（[7-2](#7-2-キャラクターを人型にするmixamo)） | Animator, Humanoid, IK |
| **5.5 攻撃アニメ** | 斬る・ガード・倒れるのアニメも Mixamo のものにする | Animation Event |
| **6. UI** | タイトル画面、HPバー、ポーズメニュー | uGUI / UI Toolkit |
| **7. ストーリー** | 惑星ごとのステージ、ボス戦、会話シーン | シーン遷移, データ管理 |
| **8. 完成！** | ビルドして、友達に遊んでもらう | Build Settings |

### 次の一歩：セーバーを光らせる（Bloom）

1. ヒエラルキーで右クリック → `Volume → Global Volume`
2. インスペクターの `Profile` 横の「New」をクリック
3. 「Add Override」→ `Post-processing → Bloom` を追加
4. `Threshold` にチェックを入れて 1、`Intensity` にチェックを入れて 1～2 くらいに
5. `Main Camera` を選び、`Rendering → Post Processing` にチェック

これでセーバーが一気にそれっぽくなります ✨

ゲームの世界観・ストーリーのたたき台は [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) にあります。

## 9. 困ったときは

| 症状 | 対処 |
|---|---|
| メニューに「Light Saber」が出ない | 画面下の **Console** に赤いエラーがないか確認。エラーがあるとスクリプトが読み込まれません |
| `InvalidOperationException: You are trying to read Input using the UnityEngine.Input class...` | [ステップ3](#ステップ-3入力設定を確認エラーが出たときだけ) の入力設定を「Both」に |
| ピンク色の物体がある | マテリアルの問題。`Light Saber → プロトタイプシーンを作成` をもう一度実行 |
| マウスカーソルが消えて操作できない | `Esc` キーで戻ります |
| 人型モデルが真っ白・色が付かない | FBX を選んで `Light Saber → 選んだモデルの色を直す`（README の 7-2 ⑤） |
| セーバーが手から離れる | `Assets/LightSaber/Scripts` を最新版に上書きする（README の 7-2 ④） |
| 人型モデルが地面に埋まる・浮く | スクリプトを最新版に上書きしてから、もう一度「セットアップ！」。それでもズレるなら `Player` の `Character Animator` → `Model Height Offset` で調整（埋まるならプラス） |
| 歩くと一瞬ワープする | スクリプトを最新版に上書きしてから、もう一度「セットアップ！」（アニメのつなぎ目をなめらかにする設定が入ります） |
| 人型モデルが T の字のまま動かない | アニメの FBX を「Without Skin」でダウンロードしたか確認し、もう一度セットアップする |
| 街灯の光が近づくとパッと点いたり消えたりする | `Edit → Project Settings → Graphics` で使っている URP の Renderer を選び、Rendering Path を **Forward+** にする |
| `Console` に `NoSubscription` と出る | Unity AI の案内なので無視してOK（`Window → Package Manager` で AI Assistant を Remove すれば消える） |
| 何か壊した… | Git を使っていれば元に戻せます。こまめに保存（コミット）しましょう |

**学習におすすめ**

- エラー文はそのまま検索すると、だいたい誰かが解決しています

> 個人の練習なら問題ありませんが、ゲームを公開・配布するときは「光剣」「ビームブレード」など
